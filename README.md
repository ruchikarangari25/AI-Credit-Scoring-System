# AI-Based Credit Scoring & Loan Risk Assessment

## Overview
A machine learning-based system that predicts loan approval
and assesses credit risk using applicant financial and
demographic data.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning

## Features
- Data preprocessing
- Exploratory Data Analysis
- Feature engineering
- Classification
- Model evaluation

## Project Workflow
Data → Preprocessing → EDA → Feature Engineering → 
Model Training → Evaluation → Loan Prediction
